# Prism marks

The AGPL covers first-party source. It does not grant the Prism name, logos, or review badges.

## Allowed without asking

- Truthful reference: "compatible with Prism packages", "reads `.prism` files", "fork of the Prism extension source".
- Stating that a build is unofficial.
- Using the word Prism as an adjective plus a generic noun when describing this project ("the Prism extension").

## Not allowed

- Calling a different runtime, store listing, installer, or registry "Prism", "official Prism", or "reviewed by Prism".
- Using Prism logos or wordmarks in a way that implies sponsorship.
- Domain names, extension names, or organisation names that are just Prism or a confusing variant.

Independent clients, servers, and extensions that implement the package format are welcome. They must use their own name. A `.prism` file is not a safety claim.

Registration of marks is a separate legal step for the copyright holder. Until then, this file is still the project rule for copy and forks.
