# Code of conduct

This is a small, security-minded community around an AGPL product and an open package format.

## Expected

- Assume good faith in technical disagreement.
- Stay on the bug or the design. Do not harass, threaten, or pile on.
- Do not demand maintainer attention with `@` pings or "please triage this".
- Do not file security issues in public trackers (`SECURITY.md`).
- Do not submit changes whose main purpose is to appear as a contribution.

## Unacceptable

Harassment, hate speech, sexualised attention, doxxing, or using the tracker to abuse people. Publishing exploit details that put users at risk. Social-engineering maintainers for access or exceptions to the capability gate.

## Enforcement

Maintainers may warn, close threads, block, or revert. Reports of conduct problems go through the same private channel as security reports when they involve harm, otherwise as a GitHub contact to the repository owner.

This is not a substitute for code review or for `npm run scan`.
